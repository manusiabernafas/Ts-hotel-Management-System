# 🏨 TS Hotel Management System (Neo-Brutalism Edition) 🌸🌊

An intuitive, full-featured Hotel Management and Room Reservation System redesigned with a **Neo-Brutalism Pastel Pink & Blue** visual aesthetic.

---

## ✨ Features & Redesign Highlights

- **Neo-Brutalism UI Style**:
  - High-contrast typography with bold geometric styling.
  - Soft pastel palette: **Pastel Pink** (`#FFB3C6`, `#FFE5EC`) and **Pastel Sky Blue** (`#A2D2FF`, `#E7F5FF`).
  - Solid 3px borders with hard offset drop-shadows (`4px 4px 0px #121212`).
  - Tactile, playful buttons with active press animations.
  - Retro window frames for auth dialogs, booking modals, and analytics charts.
- **Guest Room Reservation**:
  - Explore room categories, capacities, and nightly rates.
  - Interactive room booking flow with check-in/out scheduling.
  - Real-time booking status indicators (`Available` vs `Booked Out`).
- **Guest Dashboard**:
  - Track active room reservations, stay dates, and payment totals.
- **Admin Management Panel**:
  - Analytics dashboard with live booking metrics and revenue charts.
  - Room inventory management (create, update rates, toggle availability, delete).
  - Guest user directory management.
  - Booking schedule administration.

---

## 🛠️ Tech Stack

- **Frontend**: Angular 18, TypeScript, Bootstrap Icons, Ngx-Charts
- **Backend**: Node.js, Express.js
- **Database**: PostgreSQL
- **Theme**: Neo-Brutalism (Pastel Pink & Blue)

---

## 🚀 Getting Started

### 1. Frontend Setup
```bash
cd Web
npm install
npm start
```
The application will launch at `http://localhost:4200/`.

### 2. Backend Setup
```bash
cd backends
npm install
npm start
```
The API server will listen on the configured port.
